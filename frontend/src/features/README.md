# Features

Cada pasta corresponde a um dos 13 módulos funcionais definidos em [`docs/03_ARCHITECTURE.md`](../../../docs/03_ARCHITECTURE.md): `auth`, `users`, `dashboard`, `clients`, `projects`, `landing-pages`, `google-ads`, `analytics`, `reports`, `insights`, `library`, `ai`, `settings`.

Estas pastas estão vazias propositalmente — são a organização de destino para quando cada módulo for implementado, a partir da Sprint 1. Nenhuma lógica de negócio foi adicionada nesta Sprint 0 (fundação técnica apenas).

O módulo **SEO**, definido em `04_AI_ORCHESTRATION.md` e `06_API.md`, não tem pasta aqui de propósito: sua ativação está prevista para a Versão 2.0 (ver `07_ROADMAP.md`), fora do MVP.
